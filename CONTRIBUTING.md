# Contributing to Forensic Studio 2.0

Thank you for your interest in contributing to Forensic Studio 2.0! Contributions from the digital forensics and cybersecurity community are welcome.

## Reporting Bugs and Requesting Features

* Bug Reports: If you encounter an issue while running Forensic Studio 2.0, please open an [Issue](https://github.com) on GitHub. Include your operating system, Python version, Volatility 3 version, and steps to reproduce the error.
* Feature Requests: To suggest a new forensic workflow, plugin integration, or UI improvement, open an Issue describing the use case and expected behavior.

## Submitting Code Changes (Pull Requests)

1. Fork the repository and create a new branch for your feature or bug fix (git checkout -b feature/your-feature-name).
2. Ensure your code follows clean Python conventions and does not break existing Volatility 3 plugin execution or evidence integrity checks.
3. Test your changes locally before submitting.
4. Open a Pull Request describing what you changed and why.
